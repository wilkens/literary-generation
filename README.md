# AI as a Tool for Simulation-Based Experiments in Literary Studies

This repository contains code, data, and analytical pipelines supporting the article 
["AI as a Tool for Simulation-Based Experiments in Literary Studies"](https://arxiv.org/a/wilkens_m_1.html).

The project investigates the ability of GPT-5 and other LLMs to simulate human-authored literary texts across multiple genres, especially high-status (prize-nominated) books.

## Directories

### 1. `metadata/`
This directory holds index tables for the contemporary human-authored literature corpus:
* **`CONLIT_META.csv`**: Contains core info for 2,750+ human-authored novels. Sourced from the original [CONLIT dataset](https://doi.org/10.6084/m9.figshare.21166171.v1).
* **`CONLIT_META_PLUS.csv`**: Contains some corrections and improvements to the CONLIT metadata. This is what's used in the article.

### 2. `prompts/`
Contains JSON lines (`.jsonl`) files specifying the exact instructions sent to the API:
* **`basic/`**: Simple instructions for generating basic book chapters (e.g., across GPT-3.5, 4, and 5 models).
* **`complex/`**: Complex, constraint-driven prompts tailored to mystery (`my`), science fiction (`sf`), and prize-winning (`pw`) genres.
* **`bios/`**: Prompts to generate corresponding author biographies.

### 3. `generations/`
Includes the raw text generated by the AI models in JSON format:
* **`basic/`**: Text generated under basic prompts (`chapters_plain_[model]_generations.json`).
* **`complex/`**: Text generated under complex instructions (`chapters_complex_[genre].json`).
* **`bios/`**: Text files with simulated author biographies (`generated_bios_[genre].jsonl`).

### 4. `embeddings/`
Precomputed document embeddings of all texts:
* **`basic_prompt/`**: Embeddings for the basic-prompt output texts.
* **`complex_prompt/`**: Embeddings for the complex-prompt output texts.
* **`human/`**: Segmented sentence/chunk embeddings for the human-authored corpus.

### 5. `results/`
Pickled outputs (`.pickle`) and a CSV for derived results:
* Contains pre-calculated weighted average embeddings for the human corpus (`emb_mean.pickle`) and for the generative models. Saves loading and compute time in notebooks.
* **`predicted_author_bios.csv`**: Data for synthetic bio unmasking study.

### 6. `libraries/`
* **`fightinwords.py`**: A custom version of Jack Hessel's [implementation](https://github.com/jmhessel/FightingWords) of the "Fightin' Words" method of Monroe, Colaresi, and Quinn.

### 7. `notebooks/`
* **`analysis.ipynb`**: Most of the analytical results and visualizations presented in the paper.
* **`eda_generations.ipynb`**: Exploratory analysis of the generated texts, plus code for Fightin' Words (requires separate access to the full CONLIT corpus).

### 8. `figures/`
* Contains all figures and interactive  visualizations (available as static PNGs or interactive HTML pages).
* The `frozen-for-pub/` folder preserves visual assets for manuscript use. UMAP projection is non-deterministic, so figures change on each run.

## Getting Started & Dependencies

All dependencies are cataloged in `packages.txt`. To run the notebooks locally, set up a virtual environment and install the required libraries:

```bash
# Install the required packages
pip install -r packages.txt
```
